# Site Worker

One Worker serves the whole site on the free plan:

- **Static Assets** (`frontend/public`, generated by `monitor deploy`): HTML routes,
  `/data/*` JSON, hashed `/assets/*`. These requests never invoke the Worker.
- **Code** runs only for `assets.run_worker_first` paths: `/preview/*`. The Telegram
  Mini App API is served by the bot process, not by this Worker.

`/preview/*` validates the route, reads the exact content-addressed preview JSON from
its own assets (`env.ASSETS`), verifies the document identity, renders a 1200×630
card with Browser Run, and caches successful PNGs by the full request URL. Missing or
mismatched states return non-cacheable 404 responses; read/render failures return
non-cacheable 502 responses.

Browser Run Quick Actions require a compatibility date of at least `2026-03-24`.
They are unavailable in local-only mode, so the browser binding uses
`"remote": true`; live development therefore consumes Browser Run quota. `npm test`
does not call the remote renderer. `npm run check` runs types, unit tests, TypeScript,
and a `wrangler deploy --dry-run` bundle. A plain `fetch` handler is enough for one
route family.

The Worker is `registrar-monitor.spooktaken.workers.dev`; `website.base_url` in
`settings.toml` is that origin. Production deployment is described in
`docs/operations.md`.
