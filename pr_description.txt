⚡ Optimize instructor population with mapped lookup and batched updates

💡 **What:**
- Pre-fetched the `(course_code, section_code)` mapping into an in-memory dictionary (`section_map`) using a single `SELECT` query.
- Completely eliminated the need to query the database inside the loop for every row.
- Grouped all instructor updates into a list and utilized `executemany()` to perform a bulk update at the end, minimizing database roundtrips.

🎯 **Why:**
- The previous implementation suffered from a clear N+1 query problem, doing a separate `SELECT` query for every single section inside a loop that goes through thousands of rows of an Excel spreadsheet. This caused immense bottleneck overhead from context switching between Python and SQLite.

📊 **Measured Improvement:**
- A mocked benchmark simulating a ~10,000 row database and matching mock Excel sheet observed the following runtime results:
  - **Baseline (N+1 queries):** ~7.90 seconds
  - **Optimized (Mapped lookup & executemany):** ~0.08 seconds
  - **Improvement:** ~98.9% reduction in processing time (roughly 100x faster).
