# Domain docs

Registrar Monitor is a single-context repository.

Before exploring or changing behavior:

- read the glossary and lasting decisions in `docs/architecture.md`;
- use glossary terms in issues, tests, documentation, and code review findings.

If a needed domain term is missing or ambiguous, use `/domain-modeling`. If a
proposed change contradicts a decision in `docs/architecture.md`, state the conflict instead of silently
overriding it. Missing domain material is created lazily when a real term or
decision is resolved.
